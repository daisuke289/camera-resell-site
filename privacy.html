プライバシーポリシー

最終更新日: 2026年10月3日

camera-resell（以下「本ツール」）は、開発者本人（廣瀬大輔、以下「開発者」）が個人で運用する中古カメラの仕入れ・在庫・販売の管理ツールです。本ツールの利用者は開発者本人のみであり、一般の利用者を対象としていません。

1. Googleユーザーデータの利用

本ツールはGoogle APIを通じて、開発者本人のGoogleアカウントのGmailから、仕入れ先（フリマアプリ・オークション・店舗等）が送信した購入確認メールを読み取ります。要求する権限は読み取り専用（gmail.readonly）のみで、メールの送信・変更・削除は行いません。

2. 取得する情報と利用目的

購入確認メールに含まれる商品名、購入日、購入金額、注文番号、仕入れ先の名称を取得し、開発者本人の在庫台帳に記録するためにのみ利用します。それ以外の目的には利用しません。

3. 保存場所と保護

取得した情報は、開発者本人が管理するコンピュータ上のデータベースに保存します。Googleアカウントの認証情報（トークン）は同じコンピュータ上にのみ保存し、第三者のサーバーへ送信しません。

4. 第三者への提供

取得したGoogleユーザーデータを第三者に提供、販売、共有することはありません。広告や分析のために利用することもありません。

5. データの削除

開発者は、Googleアカウントの設定からいつでも本ツールのアクセス権を取り消すことができます。保存済みのデータは、開発者が在庫台帳から削除することで消去されます。

6. Google APIサービスのユーザーデータポリシーの遵守

本ツールによるGoogle APIから取得した情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

7. 連絡先

本ポリシーに関するお問い合わせ: daisuke289@gmail.com

Privacy Policy

camera-resell is a personal inventory tool operated solely by its developer (Daisuke Hirose). It accesses the developer's own Gmail account through the Google API with the read-only scope (gmail.readonly) to read purchase-confirmation emails and record purchased items (item name, purchase date, price, order number, seller) in a local inventory database on the developer's computer. Data and credentials are stored only on that computer and are never sold, shared or transferred to third parties, nor used for advertising. Access can be revoked at any time from the Google Account settings. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Contact: daisuke289@gmail.com
